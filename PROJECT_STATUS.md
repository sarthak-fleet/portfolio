# Project Status

Last updated: 2026-06-08

## Current Scope

sarthakagrawal.dev is a personal Astro portfolio site for Sarthak Agrawal. It
is a static Cloudflare Pages site that presents AI infrastructure and product
engineering work through an interactive terminal hero, architecture visuals,
case studies, GitHub-sourced project archive, resume, about page, and future
writing surface.

## Done

- Astro 5 static site with Tailwind v4, React islands, MDX content collections,
  command palette, terminal hero, and Cloudflare Pages deployment config.
- Core routes exist for home, work case studies, projects, about, resume, and
  blog placeholder.
- Editable content locations are documented for site metadata, experience,
  resume data, expertise, socials, case studies, and blog posts.
- GitHub project stats and project archive are fetched at build time with a
  graceful fallback when no token is configured.
- Resume PDF generation is documented through the GitHub Action and local
  fallback path.
